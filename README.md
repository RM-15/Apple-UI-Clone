<h2>Key Features & CSS Techniques</h2>
<ul>
  <li><b>Glassmorphism Navbar : </b>Created using <i>backdrop-filter: blur()</i>for that iconic traslucent frosted-glass blur.</li>
  <li><b>Fluid Design :</b> Used the <i>clamp()</i> function  for typography and spacing to ensure the site scales perfectly without hundreds of media queries. </li>
  <li><b>Pure CSS Animations :</b> High-end transitions and the Apple TV section movements are handled entirely via <b>Keyframes</b>.</li>
  <li><b>Zero-JS Accordian :</b> The footer uses <i>&lt;details&gt;</i> and <i>&lt;summary&gt;</i> to create an interactive mobile menu without any JavaScript.</li>
</ul>
<h2>Technical Challenges & Learning </h2>
<h3>The Apple TV+ Animations</h3>
<p>Replicating the Apple TV+ carousel was the highlight of this project. Since Apple uses Heavy JavaScript for their animations, I had to find a way to mimic that "cinematic zoom" using only <b>CSS Animations</b>.</p>
<ul>
  <li> <b>The Solution :</b> I collaborated with AI to refine the timing of the <b>Keyframes</b>, ensuring that the scaling and opacity transitions felt smoooth rather than robotic.</li>
</ul>
